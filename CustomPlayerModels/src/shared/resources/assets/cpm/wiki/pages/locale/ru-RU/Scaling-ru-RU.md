<a name="supported-mods"/>

### Поддерживаемые моды


<a name="pehkui"/>

#### Pehkui
Только в 1.14+  
Можно масштабировать размер игрока, здоровье, движение и различные атрибуты:  
Название способа: `pehkui`  
[CurseForge](https://www.curseforge.com/minecraft/mc-mods/pehkui), [Modrinth](https://modrinth.com/mod/pehkui)  


<a name="chiseled-me"/>

#### Chiseled Me
Только в 1.10.2 и 1.12.2  
Поддерживает только масштабирование сущности  
Название способа: `chiseledme`  
[CurseForge](https://www.curseforge.com/minecraft/mc-mods/chiseled-me)  


<a name="artemislib"/>

#### ArtemisLib
Только в 1.12.2  
Поддерживает только масштабирование сущности, ширину и высоту  
Название способа: `artemislib`  
[CurseForge](https://www.curseforge.com/minecraft/mc-mods/artemislib)  


<a name="server-settings"/>

## Настройки сервера
Масштабирование некоторых атрибутов по умолчанию отключено; его нужно включить на сервере [командой /cpm](https://github.com/tom5454/CustomPlayerModels/wiki/The--cpm-command-ru-RU#scaling).
