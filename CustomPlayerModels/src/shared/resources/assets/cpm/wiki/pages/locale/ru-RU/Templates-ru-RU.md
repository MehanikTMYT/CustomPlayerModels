<a name="using-templates"/>

## Использование шаблонов
Шаблоны — готовые модели, которые можно добавить к модели игрока.  
Шаблоны можно импортировать через «Редактировать/Добавить шаблон».  
Шаблоны можно настраивать с помощью аргументов шаблона, доступных в дереве модели.  


<a name="templates-with-textures"/>

### Шаблоны с текстурами
Текстуры шаблона могут быть предустановленными или добавляться к текстуре скина с помощью аргумента текстуры, доступного в дереве модели.  
Для добавления текстуры шаблона к скину нужен лист текстуры больше обычного.  
Выберите «Разместить текстуру», затем задайте U/V слева и установите размер текстуры в 1. Нажмите «Разместить текстуру», чтобы нарисовать предустановленную текстуру шаблона на листе по текущим координатам U/V.


<a name="creating-templates"/>

## Создание шаблонов
Создайте проект шаблона: «Новый/Новый шаблон» или «Редактировать/Преобразовать в шаблон».  
Экспортируйте шаблон: «Файл/Экспорт», затем выберите «Шаблон» и загрузите текст в [GitHub Gist](https://gist.github.com/).


<a name="template-arguments"/>

### Аргументы шаблона
Аргументы шаблона позволяют настраивать части. Сейчас поддерживаются только аргументы цвета.  
Добавьте аргумент шаблона и привяжите к нему элементы в разделе «Части» с помощью кнопки добавления.
