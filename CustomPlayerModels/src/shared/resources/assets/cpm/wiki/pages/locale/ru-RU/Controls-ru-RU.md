## Управление в редакторе

<a name="camera"/>

### Камера:
Удерживайте среднюю кнопку мыши для вращения вида. Удерживайте Shift и среднюю кнопку мыши для перемещения вида.  
В меню «Редактировать/Настройки» можно выбрать правую кнопку мыши.


<a name="spinners"/>

### Поля изменения чисел:
![Поле изменения числа](https://github.com/tom5454/CustomPlayerModels/wiki/images/spinner.png)  
Удерживайте Shift для увеличения/уменьшения на 0.1  
Удерживайте Ctrl для увеличения/уменьшения на 10  
Удерживайте Alt для увеличения/уменьшения на 0.01  
Удерживайте Alt+Shift для увеличения/уменьшения на 0.001  
Удерживайте Ctrl+Shift для увеличения/уменьшения на 100  


<a name="image-editor"/>

### Редактор изображений
Ctrl+щелчок выбирает цвет под курсором.


<a name="editor"/>

### Редактор
Ctrl+Z Отменить
Ctrl+Y Повторить


<a name="in-game-controls-keybindings"/>

## Управление в игре (назначение клавиш)
Меню жестов (по умолчанию G):  
![Меню жестов](https://github.com/tom5454/CustomPlayerModels/wiki/images/gestures_menu.png)  
Управление пользовательскими анимациями и назначение клавиш быстрого доступа.  
Быстрый доступ 1-6: клавиши быстрого доступа к пользовательским анимациям  
Переключить отрисовку: включение/отключение отрисовки пользовательской модели.  


<a name="setting-up-quick-access"/>

### Настройка быстрого доступа
Наведите курсор на выбранную позу или жест и нажмите клавишу быстрого доступа, чтобы назначить её.
