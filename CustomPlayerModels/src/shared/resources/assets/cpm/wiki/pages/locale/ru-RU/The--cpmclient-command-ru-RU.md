# Команда `/cpmclient`
Добавлена в 0.6.15

> [!NOTE]
> Версии Forge с 1.14 по 1.17 и версии Fabric ниже 1.19 не поддерживают клиентские команды
> В этих версиях команда отключена.

> [!NOTE]
> Это клиентская команда CPM; о серверной команде `/cpm` см. [здесь](https://github.com/tom5454/CustomPlayerModels/wiki/The--cpm-command-ru-RU)


<a name="subcommands"/>

### Подкоманды:
* [profile](#profile)
* [safety](#safety)
* [animate](#animate)
* [set_model](#set_model)
* [reset_model](#reset_model)


<a name="profile"/>

## profile
Использование `/cpmclient profile <target>`  

Открывает меню социальных настроек выбранного игрока  
Цель: имя игрока


<a name="safety"/>

## safety
Открывает меню настроек безопасности


<a name="animate"/>

## animate
Использование: `/cpmclient animate <animation name> [value (0-255)]`  
Воспроизвести анимацию для своего персонажа.  
Анимации, управляемые командами, разрешены только при наличии префикса `client:`.  
Значение: 0: сбросить позу/жест, 1: воспроизвести позу/жест; для слоёв со значением: 0-255, для переключателя: 0-1; оставьте пустым для смены состояния.


<a name="set_model"/>

### set_model
Использование: `/cpmclient set_model <model file>`  
Заменить текущую модель моделью из указанного файла.  
Работает только на сервере с установленным модом.  
Действие аналогично использованию меню моделей.  


<a name="reset_model"/>

### reset_model
Убрать текущую выбранную модель и разрешить загрузку из скина.  
Действие аналогично кнопке «Загрузить из скина» в меню моделей.
