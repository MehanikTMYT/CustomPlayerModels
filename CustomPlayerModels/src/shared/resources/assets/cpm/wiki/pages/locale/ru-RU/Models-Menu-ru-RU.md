# Меню моделей

> [!NOTE]
> Для этой функции на сервере требуется CPM.

![Снимок меню моделей](https://github.com/tom5454/CustomPlayerModels/wiki/images/models_menu.png)

Меню моделей позволяет менять модель прямо во время игры.
Экспортируйте модель с помощью [режима «Модель»](https://github.com/tom5454/CustomPlayerModels/wiki/Exporting-ru-RU#model-file) 

Кнопка `Load from Skin` (ранее `Reset Skin`) убирает активную модель `.cpmmodel` и загружает модель из [скина](https://github.com/tom5454/CustomPlayerModels/wiki/Exporting-ru-RU#stored-in-skin).


<a name="folders"/>

## Папки
Меню моделей поддерживает папки с моделями.  
Можно поместить в папку `icon.png` и `description.txt`, чтобы задать её значок и описание в меню моделей.


<a name="importing"/>

## Импорт
Для импорта перетащите файлы `.cpmmodel` в окно Minecraft, пока открыто меню моделей.


<a name="models-popup"/>

## Окно моделей

> [!NOTE]
> Чтобы смена скина работала, редактор нужно открыть с главного экрана!

![Снимок окна моделей](https://github.com/tom5454/CustomPlayerModels/wiki/images/models_popup.png)  
Можно выбрать модель и нажать `Upload Skin`, чтобы преобразовать существующий `.cpmmodel` в экспорт скина.  
Для этого файл `.cpmmodel` должен быть экспортирован с включённой совместимостью со скином.

Кнопка «Сменить скин» заменяет текущий скин выбранным.
