
<a name="exporting-models"/>

## Экспорт моделей

Есть ~~три~~ два способа экспорта модели:  
* [Хранение в скине](#stored-in-skin)  
* [Файл модели](#model-file)  
* [Base64 (только для разработчиков, не для обычных игроков)](#base64)  


<a name="stored-in-skin"/>

### Хранение в скине
Модель хранится в неиспользуемой области скина Minecraft.  
Этот режим работает на стандартных серверах и серверах без мода.  
Но менять модель во время игры нельзя.  
[Подробнее ниже](#skin)


<a name="model-file"/>

### Файл модели
Модель хранится в файле `.cpmmodel` в папке `<your minecraft directory>/player_models`.  
Для этого режима на сервере должен быть установлен мод/плагин; на стандартных серверах он не работает.  
Модель можно менять во время игры через `Gestures Menu/Models`.  
[Подробнее ниже](#exporting-as-local-model)


<a name="base64"/>

### Base64
Модели Base64 предназначены для владельцев серверов и создателей карт.  
Модели можно загружать [командами](https://github.com/tom5454/CustomPlayerModels/wiki/The--cpm-command-ru-RU#setskin) или через [API](https://github.com/tom5454/CustomPlayerModels/wiki/API-documentation-ru-RU#set-model).  
Этот вариант предназначен только для разработчиков.  


<a name="skin"/>

## Скин
Чтобы использовать пользовательские модели в игре, экспортируйте их через редактор и загрузите экспортированный скин.

![Окно экспорта скина](https://github.com/tom5454/CustomPlayerModels/wiki/images/export_gui.png)

Нажмите кнопку «...», чтобы выбрать выходной файл, затем нажмите «Экспорт». Базовый скин можно изменить кнопкой «Сменить стандартный скин». Этот скин будет виден игрокам без мода; по умолчанию загружается текущий скин.
Настройки слоя скина используются [для создания пользовательских анимаций](https://github.com/tom5454/CustomPlayerModels/wiki/Animations-ru-RU#custom-animations-encoding).


<a name="data-overflow"/>

### Нехватка места для данных
Если модель не помещается в неиспользуемую область файла скина, загрузите её одним из следующих способов:
- Мой сайт хранения текстов: выберите `Upload Paste`. Имя сохранённого текста можно изменить (загруженные тексты доступны в «Редактировать/Сохранённые тексты»; ограничения сайта — 15 текстов и 100kB на файл).
- [GitHub Gist](https://gist.github.com/): выберите `Upload Gist`. Нажмите `Copy`, создайте новый Gist/Pastebin и вставьте скопированные данные модели. Затем скопируйте URL созданного Gist и вставьте в нижнее текстовое поле.
- Репозиторий GitHub: поместите данные модели в текстовый файл в своём открытом репозитории и укажите ссылку на него.

> [!NOTE]
> Используйте GitHub Gist только при наличии активной учётной записи GitHub!  
> Присоединитесь к [серверу CPM в Discord](https://discord.gg/mKyXdEsMZD) и выполните `/paste-register` в канале #commands, чтобы увеличить лимиты хранения текстов
> Для использования моего сайта хранения текстов нужна действительная учётная запись Minecraft!

![Окно экспорта при нехватке места](https://github.com/tom5454/CustomPlayerModels/wiki/images/export_overflow_popup.png)

Нажмите «Ок» для завершения экспорта.

После экспорта загрузите полученный файл скина как свой скин Minecraft через лаунчер Minecraft или сайт Minecraft.
Данные модели записываются в неиспользуемую область скина, поэтому без установленного мода они не видны.
Если лаунчер сообщает, что скин не удалось загрузить, попробуйте перезапустить его.

На многопользовательских серверах модель загрузится у всех, у кого установлен мод.


<a name="exporting-as-local-model"/>

## Экспорт в локальную модель
> [!NOTE]
> Для этой функции на сервере требуется CPM.

Можно экспортировать модель как локальную. Такие модели можно менять через «Меню жестов/Модели» на серверах с установленным Customizable Player Models и в одиночной игре, в том числе во время игры.  
![Окно экспорта модели](https://github.com/tom5454/CustomPlayerModels/wiki/images/export_model.png)  
Для экспорта локальной модели откройте «Файл/Экспорт» и переключите кнопку «Режим экспорта: ???» на «Режим экспорта: Модель».  
Название используется как имя файла. Для модели можно задать значок.
Нажмите «Экспорт».  
Примените модель через `Edit/Models` или в игре через `Gestures Menu/Models`.  
Выберите модель и нажмите кнопку применения под предварительным просмотром.  
Локальные модели работают только в одиночной игре и на многопользовательских серверах с установленным модом (или плагином).  
[Если модель слишком велика (больше 30kB), её необходимо загрузить на сайт](#data-overflow)  
Совместимые со скином модели можно преобразовать в обычные модели с [хранением в скине](#stored-in-skin) через меню «Редактировать/Модели» в редакторе (редактор нужно открыть с главного экрана).  
См.: [окно моделей](https://github.com/tom5454/CustomPlayerModels/wiki/Models-Menu-ru-RU#models-popup)
