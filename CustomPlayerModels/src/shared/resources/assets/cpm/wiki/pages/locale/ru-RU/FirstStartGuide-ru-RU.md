<a name="basic-controls"/>

## Основы управления

<a name="mouse-controls"/>

### Управление мышью:
$[mouseControls]()  
Позже эти настройки можно изменить в `Edit/Controls`.  


<a name="spinners"/>

### Поля изменения чисел:
![Поле изменения числа](https://github.com/tom5454/CustomPlayerModels/wiki/images/spinner.png)  
Удерживайте Shift для увеличения/уменьшения на 0.1  
Удерживайте Ctrl для увеличения/уменьшения на 10  
Числа можно вводить с клавиатуры.  


<a name="image-editor"/>

### Редактор изображений
Ctrl+щелчок выбирает цвет под курсором.  
Текстуры можно редактировать во внешнем редакторе: сохраните текстуру и измените её.  
Нажмите `Reload`, чтобы обновить текстуру из сохранённого файла.

## Использование модели в игре
Быстро проверить модель можно через `File/Test ingame`.  

Чтобы использовать модель без `Test ingame`, в том числе на серверах, её нужно экспортировать.  
Подробнее в статье вики: [здесь](https://github.com/tom5454/CustomPlayerModels/wiki/Exporting-ru-RU) (открывается в игре).
